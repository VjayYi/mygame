# 战斗框架 v0.12：拍板汇总与武器自定义方案（草案）

> 状态：草案，供评审。承接 v0.11。本版只记录 2026-11-17 用户拍板的内容，并列出武器自定义系统的两个候选方案。数值仍是第一轮校准起点。

---

## 1. 已拍板

| 项 | 决定 |
|---|---|
| 手部义体 | 左右手各 1 张卡（手合计 2 张） |
| 脚部义体 | 左右脚各 1 张卡（脚合计 2 张） |
| 大脑、躯干 | 各 1 张被动卡 + 各 1 张可打出的辅助卡 |
| 防具套装 | 有的防具套装带效果，有的不带，混合设计 |
| 击晕 | v0.11 的设计没有问题，保持不变 |
| 新手通关率 | 初始 build 一级约 60%，沿用 v0.11 的目标 |
| 进阶后二级 | 更强的 build 打二级，目标 50%～60%，不要求与成熟一级持平 |
| 大脑、躯干被动 | 数值与可打出的辅助卡一起均衡，不单独定死 |
| 难度编号中的第 4 点 | 采用月圆式记忆碎片：每打赢一级掉碎片，集齐才开更高难度 |

**关于"手脚各 1 张"的修正**：v0.11 第 3.2 节的初始 build 表里，左右手、左右脚各有 1 张卡，合计 4 张，与本次拍板一致。v0.11 第 4.1 节成熟 build 的同一结构也一致。本版不再改卡表。

## 2. 大脑与躯干的结构（已确认）

每组义体芯片 = 1 张被动卡 + 1 张可打出的辅助卡。

- **被动卡**：常驻效果，不占出牌位，不消耗能源。
- **辅助卡**：正常出牌，消耗能源。

本次要做的是：被动数值和辅助卡数值放在一起均衡，例如被动强的，辅助卡就弱一点。v0.11 消融里"大脑躯干组贡献最大"这一结论，在本版中由"被动 + 辅助卡"一起重新校准，不再只调被动。

## 3. 武器自定义系统：两个候选（未拍板）

### 方案 A：词条拼装（法杖式）

玩家把词条一个个拼到武器上，词条之间会互相作用，类似一些自定义法杖游戏的做法。

- 优点：组合自由度最高，最能体现"自定义快感"，符合玩家体验优先的取向。
- 风险：组合数量爆炸，bug 多。这一点你已经接受，但需要组合扫描脚本来找超模组合。
- 对现有结构的影响：武器的"特色"从固定技能卡，变成由词条现场拼出来的效果。武器卡的数量要重新算。

### 方案 B：承载槽 + 可变尺寸模块

武器、防具、义体芯片各有一个承载槽，槽有容量。模块有大小，能插进去的就允许存在。

- 优点：与 v0.5 已有的"重量与承载"体系一致。规则简单，玩家能一眼看出能不能装。
- 风险：只要能插进去就允许，组合依然会很多，需要和 A 一样做扫描。另外尺寸的设计决定了可玩性，比如大模块是否要更强，否则没人选。
- 对现有结构的影响：和手的承载 C、武器的重量 W 直接对应，不需要新增概念。

### 两者的关系

两者并不冲突。一个可行的组合：

- **承载容量**（方案 B）作为硬约束：决定能装多少、装多大。
- **模块的内容**（方案 A）决定装进去之后效果是什么。

这样既有"插进去就允许"的自由，也保留了可以读懂的容量预算。但这是我的建议，不是你的决定。

### 需要你选的

1. 只用 A、只用 B，还是 A + B 组合？
2. 如果选 B，尺寸用几档（建议 1～3 格，即小、中、大）？
3. 如果选 A，词条之间的相互作用是否允许"叠加无上限"，还是每件装备设上限？

## 4. 与其他部分的关系

- 武器自定义会改变武器卡的数量和结构，所以卡组公式（手 2 + 脚 2 + 武器 0～6 + 防具 0～6 + 通用 4，合计 8～22 张）在武器方案定下来之前只是暂定。
- 模块掉落（v0.11 中的"模块三选一改二选一"）需要和承载尺寸对齐，否则掉落的模块可能插不进任何槽。这一点要在模拟里验证。
- 大脑、躯干不接收爬塔中掉落的模块，只在开局改装台配置。这一条不变。

## 5. 下一步

1. 你选武器自定义方案（A、B 或 A + B）。
2. 确定后，写武器的承载与尺寸表，以及词条表。
3. 用组合扫描脚本找出超模组合，再回头调数值。
4. 更新卡组公式，并用模拟重新校准初始 build 和成熟 build。
