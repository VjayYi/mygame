# 《概率边缘》难度阶梯与新手初始状态校准 · 草案 v0.10

**日期**：2026-11-16　**状态**：草案，未拍板
**承接**：`combat-framework-v0.9-run-calibration-draft.md`
**本轮目标（用户 23:15）**
- 新手**最初状态**打一级难度，通关率约 **60%**。
- **成熟 build** 打一级难度 **90% 以上**，二级约 **80%**，逐级递减，十级约 **20%**。

**编号约定（我定的，请确认）**：一级难度 = 基础难度，不带任何进阶修正；二到十级各累加一档修正。这与 v0.8 / v0.9 的 A1～A10 错开一位，v0.8 里的修正候选作废，由本稿第 3 节取代。

## 1. 结论先说

1. **成熟 build 的曲线可以对上**：模拟结果 91% → 80% → 72% → 64% → 56% → 49% → 38% → 31% → 26% → 19%，与目标曲线各级相差不超过 2 个百分点。
2. **新手初始状态约 60% 也能对上**，但对起始构筑的强度有明确要求（第 4 节）。
3. **手工排阶梯失败了三次**，自动搭出来才行：消耗类修正（休息回复、战后回复）叠加后效果远大于相加，3 级到 4 级会从 65% 一下掉到 31%。第 5 节给出了每个修正的单项效果表，设计时直接查。
4. **这套数字依赖贪心 AI 和一堆假设**，真人新手会更弱，必须试玩后再调。

## 2. 模拟模型（v0.6，基于 v0.5）

沿用 v0.5 的整局模型：3 层、每层 12 个节点、模块 9 槽、休息与商店、狂暴（精英 9 回合、Boss 12 回合）、晕眩卡费用 2、Boss 嘲讽。变化：

- 进阶编号改为难度级别 1～10。
- 加入"模块品质系数 q"：新手阶段基础模块品质较低。
- 加入"起始构筑强度 f"：f=1 表示起始构筑具备标准构筑的全部加成（伤害 +25%、每张防御牌护盾 +2、生命 +20）。
- 校准旋钮：怪物伤害系数 S0 = **0.505**，让成熟构筑一级难度 ≈ 92%。
- 成熟构筑 = "标准构筑 + 正常品质模块"，评分取 6 把非晕眩武器的平均值。

**仍未模拟**：供能分配及冷却、校准、调取、事件节点、套装真实效果、手部差异化加成、范围攻击；出牌是贪心策略。

| 级 | 新增修正 | 怪物伤害（相对一级） |
|---|---|---|
| 1 | 基础难度 | — |
| 2 | 无路线修正 | +6% |
| 3 | 每层 +1 个精英（一个普通节点换成精英）；双怪遭遇概率 25% → 35% | +1% |
| 4 | 休息回复 -10%；战后回复 -5% | 0 |
| 5 | 掉落三选一变二选一；商店只能买 1 个模块 | 0 |
| 6 | 怪物生命 +2% | 0 |

"怪物伤害"一列是**该级相对一级的总倍率**，不是累加。所有倍率都不低于 1，阶梯没有靠削弱怪物凑出来。

**一个瑕疵**：二级是靠"+6% 伤害"撑起来的，三级却只有 +1%，伤害倍率先升后降，不好看。可以把二级换成"双怪 35% + 休息 -10% + 战后 -5%"这类轻修正，但我没有重跑验证。

## 4. 新手初始状态（目标 ≈ 60%）

**起始构筑强度 f** 和 **模块品质 q** 共同决定一级难度的通关率（6 武器 × 400 场）：

| f \ q | q=0.6 | q=0.8 | q=1.0 |
|---|---|---|---|
| 0.00（裸装） | 0% | 0% | 9% |
| 0.25 | 0% | 3% | 32% |
| 0.50 | 1% | 22% | 57% |
| 0.75 | 10% | 50% | 78% |
| 1.00（= 标准） | 33% | 72% | 91% |

**能打到约 60% 的组合**：
- **f ≈ 0.55，q = 1.0**：起始构筑拥有标准构筑约一半的加成，模块品质正常 → 62%
- **f ≈ 0.85，q = 0.8**：起始构筑几乎和标准一样，模块品质低 20% → 59%
- **q = 0.6 不可能**：哪怕起始构筑 f = 1，通关率也只有 33%。

**含义**
- "新手模块比成熟模块弱很多"这个想法行不通，模块品质压到 0.6 就无法补救。起始模块不要比成熟模块低过 20%。
- 把"起始状态"定义成**裸装**（没有任何套装加成）也不行，一级难度通关率只有 0%～9%。**起始装备本身要自带约一半的套装加成**，也就是说，基础义体和基础防具需要带基础属性，不能全靠套装补。
- 这两组起始状态在更高难度上都会很快失去竞争力：

| 起始状态 | 1 级 | 2 级 | 3 级 | 4 级 | 5 级 |
|---|---|---|---|---|---|
| f=0.85, q=0.8 | 59% | 39% | 27% | 18% | 10% |
| f=0.55, q=1.0 | 62% | 43% | 31% | 23% | 12% |

这和"通关解锁下一级难度"自然配套：玩家在一级难度打到 60%，要进二级难度就需要先解锁内容变强。

## 5. 修正效果表（设计查表用）

从成熟构筑、一级难度基线 **91.3%** 出发，**每次只加一项**，通关率掉多少（6 武器 × 300 场）：

| 修正 | 通关率 | 变化 |
|---|---|---|
| 商店只买 1 个 | 90.4% | -0.8 |
| 双怪概率 35% | 90.0% | -1.3 |
| 双怪概率 50% | 88.6% | -2.7 |
| 战后回复 -10% | 88.6% | -2.7 |
| 休息回复 -15% | 88.4% | -2.9 |
| 精英 +1 小动作 0.25 倍 | 87.9% | -3.3 |
| 掉落二选一 | 87.2% | -4.1 |
| 怪物生命 +3% | 86.7% | -4.6 |
| 怪物伤害 +5% | 84.3% | -6.9 |
| 休息回复 -30% | 82.1% | -9.2 |
| 怪物生命 +6% | 81.7% | -9.6 |
| +1 不可打断小动作 0.2 倍 | 81.0% | -10.3 |
| 精英 +1 小动作 0.60 倍 | 80.1% | -11.2 |
| 战后回复 -30% | 77.5% | -13.8 |
| 每层 +1 精英 | 77.5% | -13.8 |
| 怪物伤害 +10% | 75.3% | -15.9 |
| 怪物生命 +10% | 71.1% | -20.2 |
| +1 不可打断小动作 0.5 倍 | 65.6% | -25.7 |
| 战后回复 -50% | 61.3% | -29.9 |

**读法**
- **路线类（双怪、商店、掉落）**效果很小，每项 1～4 个百分点，适合做密集的小台阶。
- **消耗类（休息回复、战后回复）和"不可打断动作"、"怪物生命"**效果大，而且叠加后不是相加。一局有二十多场战斗，每场少回一点血累积起来很强，所以 v0.8 里的"战后回复 -50%"（-30 个百分点）单独就能毁掉一档难度。
- **对敏感度的解释**：成熟构筑从 92% 到 20%，整个十级跨度折算只相当于怪物强度提高约 30%。这意味着**模拟对数值非常敏感**，实际测试时微调幅度要很小。

## 6. 限制与风险

1. **贪心 AI 不等于真人**：真人新手出牌更差，通关率会比模拟低；高手更高。60% 这个数字需要玩家试玩来校准，模拟只能定相对关系。
2. **起始状态与成熟状态的差距**（91% 对 59%）来自"套装 + 模块品质"。如果套装解锁节奏不足以覆盖这 30 个百分点，进阶后期玩家会卡住。
3. **武器差距**：突击步枪、短刃偏弱，会让"成熟 build"变成只有 3～4 把武器可选。建议在整体校准前先修武器。
4. **护盾偏大**：v0.9 已提过，S0 = 0.505 意味着怪的单动作伤害只有 3 左右，一张防御牌就能抵掉。后续如果缩小防御数值，所有校准数字都要重来一遍。
5. **没有玩家技能杠杆**：模拟里"成熟 build"的上限是构筑强度决定的，没有考虑玩家技术、校准判定、供能调节的收益。这些会抬高实际通关率。
6. **"+1 能源"仍是质变**：它不在本稿的成熟构筑里。任何提供它的套装，需要在下一轮用专门的难度阶梯重新校准。
