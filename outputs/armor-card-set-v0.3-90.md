## 5. 平衡核对

- **预算**：新增 45 件的副防御效果价值，**45/45** 落在费用预算的 85%～120% 内。反伤、保留、闪避、条件触发类（共 27 件）价值为手估。
- **0 费副防御**：新增件里只有 **6 件** 是 0 费副防御（均为纯抽牌或带抽牌的小件），没有再增加 0 费压力；旧 45 件里仍有 30 件 0 费副防御，是否也改成“升级后才 0 费”还没定，见第 7 节。
- **主防御统一档位**：0 费 护盾 2 + 下回合护盾 +1；1 费 护盾 6；2 费 护盾 12（沿用 v0.26）。
- **供能**：防具卡不带供能参数，但吃供能修正（防御姿态下主防御 +1/+2 护盾）。每件防具的护盾卡在 100% 防御姿态下会变成 8，副防御里的护盾数字也会 +1/+2；这部分在逐卡模拟里统一核对。
- **新旧去重**：新增件刻意避开旧件已有的效果（旧件已有的“护盾保留”“下张攻击 +N”“回收防御牌”等），新写的以反伤数值更高、击晕、中毒/流血、反弹、闪避、残血爆发为主。
