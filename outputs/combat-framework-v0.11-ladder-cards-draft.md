# 战斗框架 v0.11：杀戮尖塔/月圆式难度阶梯 + 初始 build / 成熟 build 卡牌（草案）

> 状态：草案，供评审。所有数值是"第一轮校准起点"，来自 `outputs/balance/run_sim_v0.7.py` 的粗模拟，不是最终平衡。
> 承接 v0.10。用户 2026-11-16 指示：阶梯参考杀戮尖塔与月圆之夜；起始品质约为成熟的 50%（对应通关率少一半左右）；先出一套初始 build 和一套成熟 build 的卡牌。

---

## 1. 一句话结论

1. **阶梯按杀戮尖塔的"逐类拆开"重做**：精英更多 → 普通怪伤害 → 精英伤害 → Boss 伤害与回复 → 开局掉血 → 怪物生命 → 月圆式激怒 → 坏牌与商店收紧 → Boss 多一个不可打断动作。每级只加一类，累计叠加，10 级。
2. **成熟 build 实测 1→10 级：95 / 79 / 69 / 61 / 55 / 46 / 38 / 31 / 27 / 19%**（近战、远程两套成熟 build 的均值，目标 90→20%）。
3. **初始 build 一级 51%**（目标约 60%，偏低 9 个点）；初始 build 二级只有 17%，所以初始玩家不是"打到 3、4 级"，而是靠解锁内容成长。
4. **"起始品质只有成熟 50%"在模拟里要翻译一下**：通关率差一半，对应的真实强度差只有约 23%。成熟 build 要面对怪物伤害 +30% 才会掉到约 52%（和初始 build 一级持平）。原因是胜率对强度非常陡（见第 6 节），不能把"品质 50%"直接理解成"卡牌数值砍一半"。

## 2. 难度阶梯（StS / 月圆式）

### 2.1 参考体系对照

| 我们的做法 | 杀戮尖塔 Ascension | 月圆之夜噩梦 |
|---|---|---|
| 每级只加一类修正，累计叠加 | A1–A20 逐级叠加 | 噩梦 1–7 逐级叠加 |
| 精英更多 | A1 精英更常见 | — |
| 普通怪 / 精英 / Boss 伤害分开加 | A2 / A3 / A4 | 行动卡 +1～2 |
| Boss 战后回复减少 | A5 只回 75% 已损失生命 | 泉水只回 50%、绷带 -40% |
| 开局掉血、最大生命下降 | A6 开局 -10% 生命；A14 最大生命 -4～5 | — |
| 怪物生命提高 | A7 / A8 / A9 | 每级生命 +15～20% |
| 激怒（每回合永久加伤） | — | 噩梦 2 起，每回合 +1 伤害 |
| 开局塞坏牌 | A10 诅咒牌 | 初始卡组混入低效攻击牌 |
| 商店与掉落收紧 | A16 涨价、A13 金币减少 | 商店涨价约 30% |
| 怪物行动更难 | A17–A19 | — |
| 后期质变 | A20 双 Boss | 噩梦 7 / 梦魇 |

月圆之夜的"记忆碎片"分段解锁（噩梦 1–6 各掉碎片，集齐开噩梦 7）没有放进当前阶梯，只记为 U 档解锁的备选（见 7.5）。

### 2.2 十级定义（模拟里实际使用的数值）

| 级 | 新增修正 | 参考 | 成熟均值 |
|---|---|---|---|
| 1 | 基础难度 | — | 95% |
| 2 | **精英更多**：每层多 1 个精英节点 | StS A1 | 79% |
| 3 | **普通怪伤害 +40%** | A2 | 69% |
| 4 | **精英伤害 +5%** | A3 | 61% |
| 5 | **Boss 伤害 +20%**；Boss 战后只回复 75% 已损失生命 | A4 + A5 | 55% |
| 6 | **开局损失 10% 生命**；最大生命 -9% | A6 + A14 | 46% |
| 7 | **普通 / 精英 / Boss 生命 +3%** | A7–A9 | 38% |
| 8 | **月圆式激怒**：怪物每回合永久 +1% 基础伤害 | 月圆噩梦 2+ | 31% |
| 9 | **开局塞 1 张坏牌**（打不出，只占手牌）；商店只能买 1 个；战后回复 -5% | A10 + A16 | 27% |
| 10 | **模块掉落三选一→二选一**；Boss 多一个不可打断动作 | A12 + A19 | 19% |

目标曲线：90 / 80 / 72 / 64 / 56 / 48 / 39 / 32 / 26 / 20%。除第 3、4 级偏低 2～3 个点外基本命中；第 1 级 95% 比目标高 5 个点（见 7.1）。

**为什么有些数字看着奇怪**：

- 普通怪伤害要 +40% 才有 10 个点的效果，因为这一版模拟里普通战几乎不死人，死亡集中在精英与 Boss。这条可以直接解读为"普通怪不再是白送"，实际落地要换成怪物行动更痛，而不是单纯放大数值。
- 精英伤害只要 +5%、怪物生命只要 +3%，是因为模拟里精英是主要死因，对它们的小幅加强就会大幅降低通关率。这说明精英设计的容错窗口很小，见第 6 节。
- 激怒只取 +1%/回合：精英和 Boss 本来就有狂暴计时（精英第 9 回合、Boss 第 12 回合起 +0.2×基础伤害/回合），激怒是在这上面再叠一层，所以数值不能大。

## 5. 初始 → 成熟的成长路径与每组贡献

### 5.1 逐组换成成熟件（近战，一/四/七级）

| 阶段 | L1 | L4 | L7 |
|---|---|---|---|
| 0 初始 | 50% | 7% | 2% |
| 1 + 防具套装（3 件，护盾 +1） | 52% | 9% | 3% |
| 2 + 手脚义体套装（近战 +20%、伤害 +10%） | 78% | 23% | 10% |
| 3 + 大脑躯干芯片卡与被动 | 90% | 47% | 20% |
| 4 + 高周波长刀与通用卡 = 成熟 | 94% | 62% | 38% |

### 5.2 从成熟 build 拆回初始件（消融）

| 拆掉 | L1 | L4 | L7 |
|---|---|---|---|
| 无（完整成熟） | 94% | 62% | 38% |
| 防具套装 | 94% | 57% | 34% |
| 手脚义体套装 | 80% | 30% | 13% |
| **大脑躯干芯片与被动** | **43%** | **5%** | **1%** |
| 长刀（换回短刃） | 92% | 55% | 34% |
| 击晕 / 抽牌 / 返还能量（换成纯数值） | 74% | 24% | 8% |

### 5.3 读表要点

- **大脑躯干的贡献最大**（拆掉后一级从 94% 掉到 43%）。这组被动里只有"每回合开始 +1 护盾"和"第一张攻击牌 +N"，但每回合都触发，所以威力被放大。需要决定：它是否应该是最强的一组？如果是，就应该作为"第一个大解锁"；如果不是，需要降低被动、把价值转到卡牌效果。
- **击晕 / 抽牌 / 返还能量**的贡献约 20 个点，比多数纯数值升级大。这支持"机制比数值有价值"的方向。
- **武器的差异几乎没有**（拆掉长刀只掉 2～7 个点），因为模拟里旋斩的范围优势没算，且贪心出牌不会利用武器特色。结论是武器本身要靠 AoE、击晕、持械条件拉开差距，不能只靠数值。
- **防具套装只有 4～5 个点**，偏弱，需要更有特色的效果，不能只是"+1 护盾"。

## 6. 模型的限制与"品质 50% = 通关率一半"的真实含义

- 胜率对强度极陡：把怪物伤害系数 S 从 0.74 提到 0.96（+30%），成熟 build 一级胜率从 95% 掉到约 52%。也就是说，**成熟与初始真正的强度差只有约 23%，却产生了 44 个百分点的通关率差**。这就是"品质 50%"在数值上看起来远没有 50% 的原因。
- 为了让曲线不是悬崖，我给每局加了运气项：每局怪物伤害系数再乘一个 σ=0.12 的对数正态随机数，用来近似事件选择、模块运气和操作差异。没有这一项，阶梯里每一级只要差 1～2% 的数值就会让通关率掉 20～30 个点。
- 其他限制沿用 v0.10：贪心出牌，没有模拟供能比例和冷却；范围攻击没有群攻优势；事件节点没有模拟；套装用被动近似；击晕假设"一次打掉一个可打断动作"。
- 死亡位置：成熟 build 一级主要死在第三层精英和 Boss；初始 build 在高难度下几乎全死在第一层精英。后期阶梯几乎完全由精英决定，需要警惕精英成为唯一门槛。

## 7. 待你拍板的问题

### 7.1 L1 成熟通关率偏高
成熟 build 一级模拟是 95%，目标是 90%+，没问题。但初始 build 一级是 51%（目标约 60%）。要不要把初始 build 再加强一点，或者接受 50%？

### 7.2 初始 build 在高难度几乎没有机会
初始 build 二级只有 17%，三级起接近 0。是否接受"初始玩家只能打一级，解锁后才能打更高难度"？如果要让初始 build 在二级也有机会，需要放宽一级与二级之间的落差。

### 7.3 初始与成熟的模块池品质
这一版模拟里，初始 build 的模块掉落品质是成熟的 85%（解锁池更小）。要不要保留这种"解锁扩大池子"的设定，还是模块池全程不变？

### 7.4 大脑躯干被动是否过强
消融显示大脑躯干组贡献最大。要不要降低它们的数值，把价值转到卡牌上？

### 7.5 月圆式记忆碎片
要不要把"每打赢一级掉碎片、集齐才开更高难度"作为难度解锁方式，替代 StS 的"通关即解锁下一级"？

### 7.6 阶梯数值怎么落地
- 第 3 级"普通怪 +40% 伤害"和第 4 级"精英 +5%"的差距来自模拟里的死因分布，不适合直接作为玩家看到的数字。是否改成"普通怪行动更痛"之类的文案，具体数值只保留在配置表？
- 激怒 +1%/回合是否保留，还是改成月圆的 +1 点固定伤害？

### 7.7 下一步
- 补套装真实效果（含纯晕眩套装）、供能冷却、手部差异化加成。
- 补强防具套装和武器特色，让武器不再靠数值拉差距。
- 用整局模拟验证第二个成熟 build（例如"纯晕眩"或"高护盾反击"）。
