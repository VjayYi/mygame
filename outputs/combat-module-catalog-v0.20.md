# 模块目录 v0.20：距离站位 + 卡效果与终极效果差异化（草案）

> 状态：草案，供评审。**以 v0.18 为底**，替代 v0.18 与 v0.19。武器基础信息与基础卡沿用 v0.16。数值全部为候选，待模型校准。
> 设计目标：避免"终极卡 = 模块数值相加"。每个模块有一个**倾向**，让玩家在"单卡强"和"终极机制"之间取舍，鼓励玩家自己研究构筑。

---

## 00. 终极贡献原则（用户 2026-11-17 确认）

- **数值项：终极 < 单卡。** 伤害、护盾、回复比例、能源、减伤这类数字，终极卡上的单模块贡献要比该模块单卡小。
- **机制项：终极可以 > 单卡。** 流血不衰减、击杀回手、同排全体、无视护盾、分段结算这类机制，是终极卡的价值所在，保留。
- v0.19 把机制也一并压低，方向错了，**作废**。

### 相对 v0.18 的数值下调（12 处，机制不动）

| 模块 | v0.18 终极 | v0.20 终极 | 原因 |
|---|---|---|---|
| 护刃 | 护盾 +4 | 护盾 +2 | 大于单卡 +3 |
| 吸血 | 30% 回复 | 15% 回复 | 大于单卡 25% |
| 献祭刃 | 全部护盾，2 倍伤害 | 全部护盾，等量伤害 | 转化倍率 2 倍大于单卡 1 倍；"消耗全部"的机制保留 |
| 瞄准镜 | 后排 +3 | 后排 +1 | 大于单卡 +2；"后排"条件保留 |
| 消音器 | 本回合敌人攻击 -2 | 本回合敌人每次攻击 -1 | 数值大于单卡 -1；"本回合每次"的覆盖范围保留 |
| 轻装甲 | 护盾 +3 | 护盾 +1 | 大于单卡 +2 |
| 地雷布设 | 进前排受 6 伤害 | 进前排受 3 伤害 | 大于单卡的 4 点；布雷机制保留 |

### 机制强但保留、待模拟重点观察的模块

这些是"机制 > 单卡"的设计本意，不改，但模拟时要盯：
- **余烬**：终极卡击杀回手（每回合 1 次）。
- **守势**：终极卡可保留，每保留一回合伤害 +3，目前无上限。
- **循环斩**：弃掉全部手牌，每张 +3。
- **旋刃**：每打出过一张攻击，全体额外 -1，目前无上限。
- **弹药拆解**：消耗 X 张手牌，额外结算 X 段。
- **复刻**：终极卡结算两次。

如果某个跑出来明显超模，再单独加上限，不整体压。

## 1. 距离站位

### 1.1 战场结构

| 位置 | 距离 | 说明 |
|---|---|---|
| 玩家 | 0 | 固定不动 |
| 前排 | 1 | 近战敌人必须在前排才能攻击玩家 |
| 中排 | 2 | 远程、支援类敌人常驻 |
| 后排 | 3 | 狙击、召唤、治疗类敌人常驻 |

- 每排最多 2 名敌人（候选）。
- **前移规则**：敌人回合结束时，若前排为空，中排敌人前移一排；中排为空，后排前移一排。
- 敌人意图里显示它所在的排和下一步是否移动。

### 1.2 武器攻击距离

| 品类 | 攻击距离 | 特点 |
|---|---|---|
| 刀 | 1 | 标准近战 |
| 剑 | 1～2 | 能打到中排，近战里距离最长 |
| 爪 | 1 | 贴身爆发 |
| 斧 | 1 | 前排范围 |
| 拳套 | 1 | 连击 |
| 步枪 | 1～3 | 全距离，标准远程 |
| 炮筒 | 2～3 | **打不到前排**，需要拉开距离或靠击退 |
| 手枪 | 1～2 | 近距离速射 |
| 弓 | 2～3 | **打不到前排**，擅长后排 |

- 攻击距离是武器属性，不受品质影响。
- 模块可以改变距离上限（长柄延伸、枪管延伸），或移动敌人（钩索、震地斧的终极效果）。
- 远程不吃手部加成，但能打中后排；近战伤害高，但要先清前排，或者把人拉过来。这是近战和远程的身份差异。

### 1.3 和朝向的关系

距离与朝向是两套独立判定：
- **距离**决定能否选中目标。
- **朝向**决定伤害打给谁（朝敌、朝己、归零）。

## 2. 卡效果与终极效果的差异化

### 2.1 三种倾向

| 倾向 | 含义 | 玩家的取舍 |
|---|---|---|
| **卡强** | 模块卡本身很强，进终极卡后只加一点数值 | 想要稳定的单卡输出 |
| **终强** | 模块卡一般，但在终极卡上提供关键机制 | 想打造一张核心终极卡 |
| **均衡** | 两边差不多，偏功能性 | 填补构筑缺口 |

### 2.2 方向一致原则

终极效果和卡效果**类型一致**：伤害类在终极里仍是伤害，状态类仍是状态，能源类仍是能源。区别在于终极效果**更偏机制**，而不是把数字再加一遍。

### 2.3 设计意图

- 同一把武器，装 4 个"卡强"模块，会得到 4 张强力模块卡和一张普通终极卡，适合稳定输出。
- 装 4 个"终强"模块，模块卡本身平平，但终极卡会叠出多条机制，比如"流血不衰减 + 每层流血加伤 + 击杀回手"，形成一套流血流。
- 两条路线没有绝对优劣，取决于玩家的构思。

## 7. 可能的构筑方向（举例，供跑模型时选标准构筑）

| 构筑 | 核心模块 | 思路 |
|---|---|---|
| 流血流（近战） | 倒钩、割裂、毒刃、余烬 | 流血不衰减 + 层数加伤，终极卡击杀回手反复打 |
| 护盾献祭（近战） | 守势、献祭刃、护刃 | 攒护盾，终极卡一次性转化成伤害 |
| 复刻爆发（近战） | 复刻、连斩、加速 | 终极卡结算两次，打完下一张免费 |
| 多段标记（远程） | 三连发、弹道标记、灼烧弹 | 终极卡分 3 段，每段都吃标记增伤和灼烧 |
| 后排狙杀（远程） | 狙击校准、瞄准镜、穿刺箭 | 专打后排，配合弓或炮筒 |
| 能源循环（远程） | 能量回馈、复装、反应炉 | 终极卡打群体回能源，再捞回攻击牌 |

## 8. 需要确认

1. **三排站位**是否接受？每排上限 2 人是否合适？
2. **炮筒和弓打不到前排**，这是远程的硬限制。是否接受？还是改成"打前排伤害减半"？
3. **前移规则**：前排空了，敌人回合结束才前移。是否合理？
4. **终强占比约 57%** 是否合适？
5. 以下几个终极效果可能过强，需要重点模拟：余烬（击杀回手）、复刻（结算两次）、循环斩（弃全手加伤）、弹药拆解（多段结算）。
