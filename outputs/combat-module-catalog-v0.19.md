# 模块目录 v0.19：终极贡献上限 + 全表核对（草案）

> **⚠ 已作废（2026-11-17）**：本版把机制也一并压低，方向错误。以 `combat-module-catalog-v0.20.md` 为准。

> 状态：草案，供评审。替代 v0.18 模块表。距离站位、武器攻击距离、武器与基础卡沿用 v0.18 / v0.16。数值为候选，待模型校准。
> 核心原则（用户 2026-11-17 确认）：**模块单卡要强于该模块在终极卡上的单项贡献**。终极卡是多个模块合成的，单个模块给终极的数值必须低；终极的价值来自"多条机制叠在一张卡上"，而不是某一条特别强。

## 0. 本版变更

1. 新增**终极贡献上限规则**（第 1 节），所有模块按规则核对。
2. v0.18 中 46 个模块的终极效果超出规则，已全部下调（第 2 节列出）。
3. 倾向改名：原"终强"改为**机制型**，避免误解为"终极更强"。机制型的意思是：终极上给的是一条形状不同的小效果，不是更大的数字。

## 1. 终极贡献上限规则

| 编号 | 规则 | 说明 |
|---|---|---|
| R1 | **数值类 ≤ 卡效果的 50%** | 伤害、护盾、回复、状态层数，按卡效果的一半向下取整，最少 1 |
| R2 | **概率类 ≤ 卡效果的一半，且带条件** | 例：卡上 30% 击晕，终极上只能"对蓄力中的目标 15% 击晕" |
| R3 | **单个模块不能把终极卡整体变成群体攻击** | 只能给溅射、穿透一名，伤害不超过 30% |
| R4 | **降费合计 ≤ -2，终极卡费用最低 1** | 所有降费模块在终极上的效果一起算 |
| R5 | **单次打出：能源返还合计 ≤ 2，抽牌合计 ≤ 2** | 多个能源、过牌模块叠在一起也不能超过 |
| R6 | **额外结算合计 ≤ +50%** | 复刻、额外段数这类效果一起算，终极卡总伤害系数不超过 1.5 |
| R7 | **成长类必须有上限** | "每层 +X""每张攻击 +X"一律写明上限 |
| R8 | **禁止让终极卡重复打出** | 不允许回手、变 0 费、无限保留后再加伤 |
| R9 | **分段不增伤** | 终极卡分 N 段结算时，总伤害不变，只是每段可单独触发命中效果 |

**倾向定义**
- **卡强**：终极上只给一个更小的同类数字。
- **机制型**：卡效果中规中矩，终极上给一条不同形状的小效果（条件、延迟、转移、分段等），数值同样受 R1～R9 约束。
- **均衡**：距离、降费这类功能性效果，两边接近，但仍计入总上限。

## 6. 举例：上限规则下的终极卡

**远程·多段标记（步枪，橙，装 5 个模块）**：三连发、弹道标记、灼烧弹、连射、点射。
- 三连发：终极分 2 段（总伤害不变）。
- 弹道标记：下次受伤 +25%，第一段吃到。
- 灼烧弹：目标死亡时 50% 灼烧转移。
- 连射：+本回合攻击牌数，上限 +3。
- 点射：+2。

每条单独看都很小，叠在一张卡上形成"分段 + 标记 + 转移"的一套机制。这正是终极卡该有的样子：靠组合，而不是靠某个模块单独撑起来。

## 7. 待确认

1. **R1 的 50%** 是否合适？如果你觉得终极卡整体偏弱，我倾向于提高**终极卡的基调伤害**，而不是放宽 R1。
2. **终极卡基调**还没定。建议约等于该武器攻击卡 A 的 1.5～2 倍，跑模型时一起校准。
3. **R4～R6 的合计上限**（降费 -2、能源和抽牌各 2、额外结算 +50%）需要模拟验证是否卡得太紧。
