# 2026-11-04

- 用户提出想给游戏加入「类似赌博」的机制，增加不确定性与可玩性，但主要诉求仍是「让玩家有事情做」，未想好如何融合现有规则。本轮仅设计讨论，未改代码/文档。
- 本轮核心判断（建议，未拍板）：项目随机源已过剩（骰子、5 概率被动、D20），再加开奖式随机会进一步稀释玩家存在感；赌博的设计价值在「下注权」而非开奖。约束建议为：新机制改变「结果怎么被使用」而非「结果怎么产生」，不新增随机源；筹码直接用每回合已投出的 3 个结果，不引入金币等新资源。指出 3 投选 2、概率手牌、押面借力与该方向是同一骨架，建议收敛而非再开新线。
- 三候选（均未拍板、均未改代码）：①逐投收手（推荐）——3 投改逐次揭示，每投后选落袋（保底）或续投（连击倍率），第 3 投强制结算，设爆面清空未落袋部分；新增一回合 2～3 次决策，不新增资源/UI 对象，赌局单回合闭合不增存档状态。②开盘押面——敌人意图亮出后投骰前押「本回合至少出一次某面」，命中放大、落空仅损失押注本身不影响正常结算；局外配面即调赔率，10 面 3 投时某面贴 k 张至少出一次概率 1-((10-k)/10)^3：k=1 为 27.1%、k=2 为 48.8%、k=3 为 65.7%、k=4 为 78.4%，概率需在 UI 可读。③跟敌人对赌 all-in，仅建议用于精英/Boss 战，不每回合出现。
- 建议的禁区：不做纯开奖式随机、不做爆掉清零全部回合收益、不做不可读赔率、不让赌博收益流向局外（守「绝无永久数值成长」）、不做跨回合累积赌局（避免存档新增状态）。验证建议：仅用现有 4 技能、3 种遭遇做规则切片，对照现状/①/②看每回合有效决策次数与「输了自己选错」的感受；行动预算变化后旧通关率与数值不可沿用。
- 待用户拍板：要每回合多次小赌（①）还是一回合一次大赌（②）；以及赌注是否以「已投出的结果」为筹码。

- 10:37 用户否定上一轮赌博方向，认为战斗深度仍不够，明确要「增加玩家可操纵的内容」，要求参考其他类型游戏设计。本轮仅设计讨论与外网调研，未改代码/文档。
- 诊断（建议）：上一轮三候选都停在结算层，只增加决策频率、未增加可操纵状态变量。当前战斗可改变的状态仅敌人血量、自己血量、护盾（每回合清零），全是衰减型数值，没有玩家能主动设置并保留到下回合的东西，回合之间无耦合。赌博加随机、深度加状态，两者拉扯；多个高深度系统反而主动压低随机。统一解法建议：不降低随机，而是给每个随机结果多个出口，并让出口之间挂上持久状态，使坏骰不再空转。
- 本轮外部调研（只借设计原则，不照搬玩法）：Into the Breach（8×8 小棋盘、敌人提前一回合完全公开攻击格与伤害、无命中率与浮动、核心动词是推/拉而非伤害、失败可归因于布置、小棋盘为保持单回合可解）；Die in the Dungeon（骰子放网格、位置决定效果、重型/重力/迅捷/玻璃/镜像等属性交互、好站位可补偿坏骰）；Dicey Dungeons（骰子塞进装备槽、槽位有奇偶与大小限制、装备可改点数与复用）；Slay the Spire（深度在持久状态 Power/中毒/Watcher 姿态与抽弃消耗三堆循环，默认 3 能量抽 5、回合末弃整手、意图公开）；格斗（街霸 6 Drive Gauge 六格共享池供攻防移动、透支进 Burnout；GGST Roman Cancel 花半条气取消几乎任何动作；KOF13 分层取消链与防御崩溃）；工人放置（有限 token 占有限动作格、放置即阻断、部分跨回合留存；失败模式为某格过强退化成抢先手、阻断过狠使后手无辜变差）。
- 三骨架候选（均未拍板、均未改代码）：A 一维 3 格战线——敌人意图由「打你多少」改为「打几号位」，已有技能由单用途改为数值/空间双用途（剑推、盾占位、心换位），新增站位/敌人位置/意图落点/占位状态；不新增骰子与骰面，只改意图表达，纯文字 UI 可验证，顺带解决随机空转。B 骰盘——投出结果放进格位并可留存若干回合，格位有相邻协同与退化，玩家决定放哪/留多久/何时兑现/是否为凑协同牺牲本回合；深度上限最高也最贴赌博感，但状态最多实现最重，PVE 无对手抢格需靠格位退化或敌人污染造压力。C 共享资源池＋取消——攻防位移与取消共用一个池、透支虚弱、跨回合姿态改变骰面结果解释，玩家花资源取消/改写刚投出的结果与结算顺序；补上跨回合经营，但时序概念与「学习成本低」有张力。
- 推荐（未拍板）：A 打底并叠少量 C（站位消耗同一池，使「推不推」有机会成本），B 留作第二阶段或爬塔专用；赌博机制降级为局部调味，不作骨架。验证指标建议改为：空转率（最关键）、每回合有效决策次数、失败能否归因于自己的布置、单局时长是否破坏轻量定位；只用现有 4 技能与 3 种遭遇做纯文字切片，A 单独测一轮、A+C 测一轮，不动 v0.2.0、不扩章；行动预算变化后旧通关率与数值不可沿用。
- 用户此前 10/20 要求的 TCG 深度方向仍有效，C 与「堆叠/响应」方向可对齐；单骰 10 面、局内不加面不重贴、绝无永久数值成长等硬约束本轮未变。
